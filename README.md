# Image Noise Distribution Matching

Kaggle competition project for the Practical Machine Learning course (MSc Data Science, Year I, Semester I, University of Bucharest).

## The task

Each sample is a pair of 256×256 grayscale noise images. The goal is to predict whether both images were generated by the same noise distribution (`1`) or by different ones (`0`). Submissions are scored on classification accuracy.

The data has 6,078 training pairs, 1,800 validation pairs and 4,104 test pairs.

## The solution

1. **Exploration.** Comparing simple statistics of the two images (mean, standard deviation and so on) did not separate the classes. The frequency spectrum (FFT) did: matching pairs had similar spectral patterns.
2. **Features.** For each pair I computed 127 features measuring how similar the two images are. They cover correlations over the whole image and on local patches, frequency features (FFT, DCT), wavelets, rank correlations and statistical differences.
3. **Models.** I compared LightGBM, XGBoost, Random Forest and Gradient Boosting on the validation set. Then I tuned LightGBM and retrained the best models on train + validation.

**Result:** LightGBM reached 90.4% accuracy on the test set.
